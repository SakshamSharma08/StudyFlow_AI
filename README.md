# StudyFlow AI

Build a complete responsive full-stack web app called StudyFlow AI — AI-Powered Student Productivity Platform.

Create a modern student dashboard with:

Secure login/register

Dashboard with productivity overview, assignment status, study hours and upcoming deadlines

Subjects management

Assignment CRUD with priority, deadline and status

Goals with progress tracking

Exam schedule and countdowns

Study-session tracking

Analytics with charts

In-app notifications/reminders

AI Study Assistant chat for study questions and personalized study plans

Use React + TypeScript + Tailwind CSS + Supabase for authentication/database. Keep the architecture simple and beginner-friendly.

Make the UI polished, modern and responsive with a sidebar, cards, charts, empty states, loading states and form validation.

Use mock AI responses if an AI API is not configured, so the application remains fully functional.

Prioritize a working complete MVP, clean code, minimal dependencies, and no unnecessary advanced features. Generate the entire application in one go.
